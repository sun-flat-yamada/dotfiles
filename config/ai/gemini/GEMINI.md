# Google Antigravity / Gemini CLI グローバル設定

1. **日本語による対話**: ユーザーへの返答、経過報告、質問、レビューコメントはすべて日本語で記述する。
2. **英語コミット規約**: コミットメッセージは英語の Conventional Commits（`feat:`, `fix:`, `docs:` 等）に従う。
3. **機密情報の完全保護**: API キーや認証トークンを絶対に出力・コミットしない。
4. **共通規約参照**: 詳細は `~/.agents/AGENTS.md` およびプロジェクトルートの `.gemini/GEMINI.md` / `CLAUDE.md` に従う。
